# validationDeepSeaDiverQuestion
A question to set requirements to validate user input in the context of a deep sea context. 

Scenario Overview
You're developing software for a diving expedition company. Divers
need to log their maximum depth, and your programme must ensure safety
by validating depth measurements.

Validation Focus: Range Check

Your Task: Create a Python function that validates dive depth input.
Recreational diving limits are 0-40 metres. 
Reject any values outside this range and provide appropriate error
messages.

Success Criteria
Accept depths between 0 and 40 metres (inclusive)
Reject negative values with a clear error message
Reject values exceeding 40 metres
Handle non-numeric input gracefully
Display confirmation for valid entries
